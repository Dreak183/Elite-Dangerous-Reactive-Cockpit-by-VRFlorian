## About VRFlorian Reactive Cockpit
**VRFlorian Reactive Cockpit** adds responsive cockpit themes and optional single-player Story Mode content to *Elite Dangerous*.

Story Mode features include:
- Living World layer
- Mission 1 and Mission 2 campaigns
- Story Reader with clues/scanner state/location windows
- Location-aware sound and visual effects
- Saved checkpoint progress

## Installation & Updates (Upstream Behavior)
Typical upstream flow:
1. Download and extract the complete ZIP (do not run from inside ZIP).
2. Start via `START VRFLORIAN REACTIVE COCKPIT.bat`.
3. Follow launcher checks for Python/EDHM prerequisites.
4. Use **CHECK FOR UPDATES** in launcher after clean install.

Update packages are verified upstream by file size and SHA-256 before install, while preserving player configuration, cockpit assignments, mission progress, and logs.
